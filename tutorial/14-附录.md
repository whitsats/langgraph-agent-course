## A. API 速查（本教程用到的全部导入）

**基线**：`langchain 1.4.2` / `langgraph 1.2.12`（2026-09-22 核对）。

```python
# ── 模型 ──────────────────────────────────────────────────────────
from langchain.chat_models import init_chat_model
model = init_chat_model("openai:agnes-2.5-flash", base_url=..., api_key=...)
model = get_model(temperature=0)                 # 示例里的统一入口（_shared.py）

# ── agent ────────────────────────────────────────────────────────
from langchain.agents import create_agent
from langchain.agents.structured_output import ToolStrategy
agent = create_agent(
    model=..., tools=[...], system_prompt="...",
    response_format=ToolStrategy(Schema),        # 结构化交付
    checkpointer=InMemorySaver(),                # 记忆
    # middleware=[...]                           # 上下文处理等（★ 用前先 inspect 签名）
)
result = agent.invoke({"messages": [{"role": "user", "content": "..."}]}, config)
result["messages"][-1].content                   # 最终回答
result["structured_response"]                    # 结构化结果（★ 不在 messages 里）

# ── 工具 ─────────────────────────────────────────────────────────
from langchain.tools import tool
from langchain.messages import ToolMessage
model.bind_tools([...])                          # 手写循环用
ToolMessage(content=..., tool_call_id=...)       # 回灌工具结果

# ── 图 ───────────────────────────────────────────────────────────
from langgraph.graph import END, START, StateGraph
from langgraph.graph.message import add_messages
from typing_extensions import TypedDict
from typing import Annotated
from operator import add

builder = StateGraph(MyState)                    # ★ 只能 TypedDict，不支持 Pydantic
builder.add_node("a", fn)                        # 节点返回"这次的变化"
builder.add_edge(START, "a")
builder.add_conditional_edges("a", router)       # router 返回节点名
graph = builder.compile(checkpointer=cp)
graph.invoke(initial_state, config)              # config 里必须有 thread_id
graph.invoke({}, config)                         # 用磁盘上的状态继续
graph.get_state(config).values                   # 读当前状态
graph.get_state_history(config)                  # 历史 checkpoint（回放）
graph.update_state(config, {...})                # 分叉（不是回滚！）

# ── 人工中断 ─────────────────────────────────────────────────────
from langgraph.types import Command, interrupt, Overwrite
decision = interrupt({...})                      # 停下来问人
graph.invoke(Command(resume=值), config)         # 恢复（值 = interrupt 的返回值）
return {"items": Overwrite([])}                  # 强制清空带 reducer 的字段

# ── 持久化 ───────────────────────────────────────────────────────
from langgraph.checkpoint.memory import InMemorySaver                 # 开发
from langgraph.checkpoint.sqlite import SqliteSaver                   # 本地持久
from langgraph.checkpoint.postgres import PostgresSaver               # 生产（首次 cp.setup()）

# ── 知识库 ───────────────────────────────────────────────────────
from langchain_core.documents import Document
from langchain_core.vectorstores import InMemoryVectorStore
from langchain_core.embeddings import DeterministicFakeEmbedding      # 假 embedding，测试用
from langchain_text_splitters import RecursiveCharacterTextSplitter
from langchain_postgres import PGVector                               # 生产（可选）

# ── 长期记忆（跨 thread，Store）───────────────────────────────
from langgraph.store.memory import InMemoryStore          # 开发；生产换持久化 store
store.put(("memories", user_id), "fact-1", {"fact": "..."})   # namespace 用【稳定】的用户 id，不要用 thread_id
store.get(("memories", user_id), "fact-1")
store.search(("memories", user_id), query="口味", limit=3)    # 语义检索：建 store 时配 index
# agent 侧：create_agent(..., store=store)；工具里用 ToolRuntime.store 读写（见第 06 章）

# ── 流式（事件流 v3）─────────────────────────────────────────
stream = graph.stream_events(input, config, version="v3")    # beta 提示属正常
stream.messages          # 逐条消息 / 逐 token
stream.interrupts        # 待人回答的内容（审批 UI 直接用它）
stream.interrupted       # 是否停在 interrupt()
stream.output            # 最终状态（等价于 invoke 的返回值）

# ── MCP ──────────────────────────────────────────────────────────
from langchain.mcp import MCPAdapter             # ★ 新的；beta；需 langchain[mcp]>=1.4.0
```

## B. 排错表

| 报错 / 现象 | 原因 | 解决 |
|---|---|---|
| `AGENT 不调用工具`，只是自己回答 | 模型工具调用能力弱 / 工具描述太模糊 | 跑 `00_env_check.py --live`；换模型；把工具 docstring 写具体 |
| `Missing thread_id` / 提示 `configurable` | 挂了 checkpointer 但没传 `thread_id` | `config = {"configurable": {"thread_id": "..."}}` |
| 中断时报 checkpointer 相关错误 | `interrupt()` 需要 checkpointer | `compile(checkpointer=...)` |
| 恢复后从头发起（等于没恢复） | `thread_id` 不一致 | 用同一个 `thread_id` |
| 状态里的列表每轮只剩一条 | 字段没挂 reducer | `Annotated[list, add]` |
| 清空字段清不掉 | 累加 reducer 把 `[]` 当追加 | `Overwrite([])` |
| `GRAPH_RECURSION_LIMIT` | 循环步数超限 | 提高 `recursion_limit` **或**（更好）给流程加显式的重工上限与路由 |
| `structured_response` 是 `None` | 打印错位置 / 没用 `response_format` | 读 `result["structured_response"]`；检查 `create_agent(response_format=...)` |
| 结构化校验失败 | schema 太严或输入不合法 | 用 `ToolStrategy(..., handle_errors=...)` 控制重试；放宽约束 |
| 导入 `langchain.mcp` 失败 | 缺 extra | `uv add "langchain[mcp]"`（`>=1.4.0`） |
| 导入时出现 `LangChainBetaWarning` | `langchain.mcp` 是 beta | 正常，不是错误 |
| `bind_tools` 过的 model 传给 `create_agent` 报错 | v1 不支持预绑工具 | 让 `create_agent` 自己绑 |
| Postgres checkpointer 建表失败 | 忘了 `setup()` | 首次运行前 `cp.setup()` |
| checkpoint 库涨得很快 | 每轮都存快照，且没清理 | 定清理策略；用 `UntrackedValue` 排除大对象 |
| 检索读到别家数据 | 漏了元数据过滤 | 元数据过滤 + **写测试**（写法见第 09 章，注意各库语法不同） |
| `TypeError: 'dict' object is not callable` | 给 `InMemoryVectorStore` 传了字典 filter | 改用 `filter=lambda doc: ...`（只有真实向量库才吃字典） |
| `NameError: name 'np' is not defined` | 用了 `DeterministicFakeEmbedding` 但没装 numpy | `uv add numpy`（langchain-core 没有声明这个隐性依赖） |
| 检索结果过时 | 源文档删了但库里没同步 | 按 id `delete(ids=[...])` |
| 换 embedding 后结果诡异 | 新旧向量混在一个 collection | **全量重灌** |
| `UnicodeEncodeError: 'gbk' codec can't encode ...`（Windows 打印 ✅/emoji） | 控制台编码是 GBK | 示例已自动切 UTF-8（`_shared.setup_console()`）；自写脚本用 `chcp 65001` 或 `PYTHONIOENCODING=utf-8` |
| 请求发出去后**一直不返回**：不报错、光标干等 | 网关侧那个模型当前不返回 | 换 `MODEL=agnes-2.5-flash`；`--live` 已加 45s 上限，会明确告诉你"这是网关侧没回"（实测 2026-09-23 的 `agnes-3.0-flash`） |
| 跑多个例子后大面积报 `429` / "您已达到免费用户的 API 速率限制" | 免费额度的速率上限 | 歇一两分钟再跑（实测 20s 恢复）；`run_all.py` 已内置 20s/45s 自动重试 |
| 报 `403`（无权限） | 该模型需要更高额度 | `agnes-2.5-pro` 在免费额度下不可用；用 `agnes-2.5-flash` |
| 工具里注入 `runtime` 报 `TypeError: BaseModel.__init__() takes 1 positional argument...` | `ToolRuntime` 漏写泛型 | 标注写成 `ToolRuntime[None, AgentState]` |
| `LangChainBetaWarning: The v3 streaming protocol on Pregel is experimental` | 用了 `stream_events(version="v3")` | 正常提示，不是错误 |
| 换个会话就失忆（长期记忆失效） | namespace 里用了 `thread_id` | namespace 换回稳定的 user_id / 项目 id |
| `SyntaxError: invalid syntax` 在中文行 | 中文里混了 ASCII 双引号 | 用中文引号「」或转义 |

## C. 术语对照（你熟悉的词 → 这里的词）

| 你的世界 | 这里 | 一句话 |
|---|---|---|
| session_id | `thread_id` | 会话/流程实例的隔离键 |
| Redis 会话存储 / 任务持久化 | **checkpointer** | 整个状态会落库，能动断点续跑 |
| Redux store / reducer | **State / reducer** | 状态 + "变化怎么合并" |
| 中间件 | **Middleware** | 生命周期钩子 |
| Zod / class-validator | **Pydantic** + `response_format` | 数据契约 |
| REST 接口文档 | **`@tool` 的 docstring** | 给模型看的接口说明 |
| Queue 任务 | **图的节点 + 持久化** | 可中断、可恢复、可回放 |
| 审批工单 | **`interrupt()`** | 状态转移级的人工卡点 |
| 幂等 | **幂等** | 同 id 覆盖、去重标记 |
| npm / composer | **uv** | 依赖管理 |
| 云函数/容器 | **图的部署** | 见第 11 章 |

## D. 十个坑（背下来能省很多时间）

1. 忘记 reducer → 跨轮数据静默丢失
2. 忘记 `thread_id` → 报错或失忆
3. 在 `interrupt()` 之前写副作用 → 恢复时重复执行
4. 步数/轮数没上限 → 线上卡死
5. 拿正则解析模型输出 → 换个措辞就崩
6. 在 prompt 里做权限控制 → 越权
7. 把数据库向量化 → 又慢又不准还贵
8. 灌数据写在 agent 里 → 每次启动重灌
9. 断言措辞而不是行为 → 评测维护不下去
10. 失败返回假成功 → 整条流水线撒谎
